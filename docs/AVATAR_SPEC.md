## 1. המטרה

לכל שחקן יש דמות משלו: מוזיקאי מאויר, מצחיק ומלא אופי, לא ילדותי. מתחילים בדמות בסיסית. כל פריט חזותי — כובע, ז׳קט, גיטרה, אימוט — נקנה ב־XP או נפתח בזכות הישג. הדמות מופיעה בלובי האונליין, בפודיום, בטבלת הליגה, אצל החברים ובדף הבית.

**למה זה עובד:** יעד ארוך טווח שאינו הציון ("עוד 800 XP לגיטרה"), ביטוי אישי, וסטטוס חברתי באונליין.

**כלל ברזל:** קוסמטי בלבד. אין פריט שמשנה קושי, ניקוד, רמזים או זמן.

### ההמלצה: 2D, SVG בשכבות, "שלד" משלנו

- **ראשים, פנים, שיער וזקן מ־Open Peeps** (CC0): עשרות אפשרויות מוכנות בקו יד מצוין.
- **גוף משלנו עם מפרקים:** ראש, גו, שתי זרועות עם נקודת סיבוב בכתף ובמרפק, שתי רגליים, ושתי "ידיים מחזיקות" עם נקודות אחיזה לכלי.
  - הגוף מצויר בסגנון הקו של Open Peeps, כך שהכל נראה כמו יד אחת.
  - **רק כך אפשר להניע אימוטים** (אוויר־גיטרה, ניצוח) ולהחזיק גיטרה אמיתית ביד.
- **בגדים, כלים ואביזרים:** אני מצייר אותם ב־SVG באותו סגנון. Recraft הוא אופציה לפריטים מורכבים, בתוכנית בתשלום בלבד.
- **אימוטים:** אנימציות בקוד (Web Animations) על חלקי השלד.
  - אפס ספריות ואפס משקל.
  - מכבדות את הגדרת "הפחתת תנועה".
  - אפשר לעבור ל־Rive בעתיד בלי לשנות את הקטלוג.
- **מדבקות:** מדבקות מוזיקליות שאני מצייר, ובסיס של Fluent Emoji (MIT) לרגשות כלליים.
- **למה לא תלת־ממד:** האפליקציה היא PWA שרצה גם בטלפונים חלשים. SVG שוקל כמה קילובייטים, נטען מיד, נראה חד בכל גודל, מתאים את הצבעים לערכת הנושא, ומונפש בקלות.
- **הורדות:** הורדת חבילת Open Peeps (קובץ ZIP מ־openpeeps.com, CC0) תתבצע רק באישורך המפורש, כשאציין שם קובץ וגודל.

## 4. כלכלה

### 4.1 מטבע אחד: XP לבזבוז
- **יתרה לבזבוז = כל ה־XP שנצבר אי פעם − מה שהוצא.**
- קנייה **לא** מורידה XP של ליגה, דירוג, רצף או רמה. אלה ממשיכים להיספר כרגיל.
- **החנות כולה עוברת ל־XP** (כפי שסיכמנו):
  - ערכות הצבע וההקפאות/תיקוני רצף שהיו ביהלומים יתומחרו ב־XP.
  - בונוסי היהלומים (אבני דרך ברצף, פאזל זהב) יהפכו ל"XP בונוס לבזבוז", שלא נספר בליגה.
- **המרה חד־פעמית של יתרת יהלומים קיימת:** יהלום אחד = 5 XP. זה היחס בין קצב צבירת היהלומים (כ־25 ליום לשחקן פעיל) לקצב צבירת ה־XP (כ־100–150 ליום).
- **מחירים חדשים:**

| פריט | מחיר |
|---|---|
| הקפאה | 1,000 XP |
| תיקון רצף | 2,000 XP |
| ערכת צבע | 1,500–2,500 XP |

- **התמחור הסופי ייקבע אחרי מדידה של צבירת XP אמיתית** אצל שחקנים. אפשר לקרוא אותה מנתוני ה־snapshots.

### 4.2 נדירות ומחיר (לשחקן פעיל, כ־120 XP ליום)

| נדירות | צבע מסגרת | טווח מחיר | בערך |
|---|---|---|---|
| רגיל | אפור | 100–300 | 1–3 ימים |
| נדיר | כחול | 500–1,000 | שבוע |
| אפי | סגול | 1,500–3,000 | 2–4 שבועות |
| אגדי | זהב מונפש | 5,000–8,000 | 1–2 חודשים |
| הישג | צבע הליגה / זוהר | לא למכירה | — |

- **"הבא בתור":** בארון יש כרטיס "היעד שלי". בוחרים פריט, ופס התקדמות מופיע בדף הבית ("עוד 340 XP לסקסופון").
- **לא FOMO אגרסיבי:** אין טיימרים שמכריחים לקנות. "פריט השבוע" מקבל 20% הנחה, וזה הכול.

## 8. דרך מימוש מוצעת

### 8.1 מודל נתונים
```ts
// src/engine/avatar.ts (טהור)
type Slot = 'head' | 'eyes' | 'face' | 'top' | 'legs' | 'shoes' | 'hand' | 'offhand' | 'pet' | 'bg' | 'aura' | 'entrance' | 'victory' | 'frame';
interface AvatarItem { id: string; slot: Slot; rarity: 'common' | 'rare' | 'epic' | 'legendary' | 'achievement'; price?: number; unlock?: UnlockRule; name: { en: string; he: string } }
interface AvatarConfig { v: 1; body: 0 | 1 | 2; skin: number; hair: string; hairColor: number; facial: string; face: string; equip: Partial<Record<Slot, string>>; emotes: string[]; title?: string }
```
- **XP לבזבוז:** נגזר מההיסטוריה ומרשימת רכישות שרק מתווספת לה (`purchases`, אותו מנגנון של streak.ts). כך ענן או מכשיר שני מחשבים בדיוק אותה יתרה.
- **פתיחה מהישג:** פונקציות טהורות מעל `Progress` (ליגה הכי גבוהה, רצף, מפת כישורים, ניצחונות).

### 8.2 ציור ורינדור
- **רכיב `<Avatar config size pose emote />`:** SVG אחד שמורכב משכבות לפי סדר־z קבוע:

- **החלקים:**
  - כל חלק הוא רכיב SVG קטן, מכווץ ב־svgo.
  - הקטלוג נטען בעצלתיים: דף הבית טוען רק את מה שהשחקן לובש.
  - **תקציב:** עד 40KB (דחוס) לטעינה ראשונה.
