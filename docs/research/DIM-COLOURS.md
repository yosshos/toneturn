# Dominant colours from one diminished chord (2026-11-21)

**Context.** The owner pointed out that lowering one note of B°7 a half step gives a plain dominant 7th, while raising one
note a whole step gives a dominant 7♭9 voicing. Moving different notes gives many dominant colours. This document checks
every move of one or two notes by a half step or a whole step from B°7 (B D F A♭), computed exhaustively.
All the spellings are plain chord arithmetic.

**Attribution.**
- The half-step moves are Harris's, as sourced in docs/BARRY-HARRIS-THEORY.md §1 and §10: lower one note → a dominant;
  raise one note → a minor 6; the first movement.
- The whole-step and two-note colours are voicing arithmetic. The app does not label them as Harris.

## One note

| Move | Example on B°7 | Result | The four results |
|---|---|---|---|
| lower ½ (Harris) | A♭ → G: B D F G | **G7** (root, 3, 5, ♭7), root = the moved note | G7, B♭7, D♭7, E7: the brothers |
| raise ½ (Harris) | A♭ → A: B D F A | **Dm6 = Bø7** | Dm6, Fm6, A♭m6, Bm6 |
| raise a whole step | A♭ → B♭: B♭ B D F | **B♭7♭9** (root, ♭9, 3, 5), root = the moved note | B♭7♭9, D♭7♭9, E7♭9, G7♭9: the same four roots, a new colour |
| lower a whole step | A♭ → G♭: B D F G♭ | no common chord name | — |

**What this shows.** Both dominant moves reach the same four roots, the family a minor 3rd apart. Lowering a half step
gives the plain 7th. Raising a whole step gives the 7♭9 with the root on the bottom of the moved voice.

## Two notes: the dominant colours

Each example below takes two notes of B°7 and moves them. Every pattern works the same way on all four pairs of notes.

| Move | Example | Result |
|---|---|---|
| two notes a tritone apart, both lowered ½ | B → B♭, F → E | **B♭7♭5 = E7♭5** (the tritone-sub pair, ♯11 colour) |
| one lowered ½, the note a tritone away raised ½ | B → B♭, F → G♭ | **B♭7♯5** (♭13 colour) |
| one lowered ½, the note a tritone away raised a whole step | B → B♭, F → G | **B♭13** (no 5) |
| two notes a minor 3rd apart, both raised a whole step | B → D♭, D → E | **E13♭9** (no 5, 7) |
| one lowered ½, the next note up raised ½ | B → B♭, D → E♭ | **B♭7sus4** |
| one lowered a whole step, the next note up raised ½ | B → A, D → E♭ | **F7♯9** (no 5) |
| two notes a minor 3rd apart, both lowered ½ | B → B♭, D → D♭ | **B♭m7 = D♭6** |
| two notes a minor 3rd apart, both raised ½ | B → C, D → E♭ | **Fm7 = A♭6** |

One diminished chord therefore holds, on each of the four roots: 7, 7♭9, 7♭5 (♯11), 7♯5 (♭13), 13, 13♭9, 7sus4, 7♯9,
plus the m6 / m7 / 6 chords that resolve them.

## Proposed exercise: "Colours of the diminished" (per key page)

- **Material.** On the C page, start from the dim of the key's V: B°7, which is G7♭9 without its root.
  1. The four plain dominants (lower ½).
  2. Their 7♭9 (raise a whole step).
  3. The four m6 (raise ½).
  4. The two-note colours above.
  Each one resolves to its own tonic: G7 → C, B♭7 → E♭, D♭7 → G♭, E7 → A. Or all of them resolve to C, as in the
  brothers.
- **How it is played.** Close position first, then drop 2. Take 1 (the moves), then take 2 (into the resolution). The
  keys follow the coach's key order.
- **Labels.** The half-step items are titled as Harris moves. The rest are titled as colours.
